# 大庚剑阵源码分析

分析日期：2026-10-21（Asia/Shanghai）  
分析对象：本目录上一级的 React 版、HTML 版及 `yuanma.zip`。  
交付范围：源码阅读、算法解释、问题核验和运行验证；业务源码未修改。

## 先读结论

这是一个在浏览器内运行的手势控制 3D 剑阵演示。摄像头图像经 MediaPipe 提取手部关键点，程序用关节夹角判断手势，再用 Three.js 实例化网格表现游龙、护盾、莲花和大庚四种阵型。没有业务后端、账号、数据库或联网对战逻辑。

React 版适合继续开发；HTML 版是将相似业务逻辑集中到单文件、改用 CDN 依赖的独立版本，两者依赖版本和错误提示并不完全一致。React 版已经在临时副本中通过依赖安装和生产构建，浏览器模拟输入也走通了四模式控制与渲染链路；`npm run lint` 因缺少 ESLint 配置而退出。真实摄像头手势、手机适配和 HTML 版外网运行仍需另行验收。

最值得优先处理的源码问题：

1. 所有飞剑共用一个缩放状态，主剑无法按设计逐渐放大到 6 倍。
2. 运动积分固定使用 `1/60`，视觉旋转却使用真实时间，不同帧率下运动表现不一致。
3. 原说明中的“只伸食指”实际被识别为护盾；识别规则与玩法说明有偏差。
4. 摄像头和识别器缺少统一释放、失败恢复及可见的错误交互。
5. 本地 WASM 与锁定依赖包内容不同，且未提供非 SIMD 资源；兼容性需要单独验证。
