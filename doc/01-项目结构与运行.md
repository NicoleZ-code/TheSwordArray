# 01 项目结构与运行

## 1. 项目定位

项目把手势输入转换为大量飞剑的目标位置与特效。剑体通过基础几何体现场生成，没有导入剑模型文件。界面显示“青竹蜂云剑”，页面标题与文件夹使用“大庚剑阵”；其中“大庚”也是四种阵型之一。

业务逻辑完全位于前端。MediaPipe 使用训练好的模型提供关键点，业务代码中的手势分类是规则判断，并没有训练四种技能对应的专用分类模型。所谓“护盾”“雷电”“剑阵”是视觉表现，没有伤害、碰撞命中、敌人或战斗结算系统。

## 3. 技术栈和版本来源

下表 React 列来自 `package-lock.json` 的锁定结果，不把 `package.json` 的版本范围当作安装结果。

| 用途 | React 版锁定版本 | HTML 版 import map |
| --- | --- | --- |
| UI | React / React DOM 19.2.3 | 18.2.0 |
| 3D | Three.js 0.182.0 | 0.160.0 |

## 4. 两个版本的实际区别

| 方面 | React 版 | HTML 版 |
| --- | --- | --- |
| 组织 | TypeScript 多文件组件 | 单 HTML 中的 JavaScript/JSX |
| 依赖交付 | 包管理器安装，Vite 构建 | CDN import map 和浏览器 Babel |
| 模型 / WASM | `/models/…` 同站点路径 | jsDelivr WASM、Google Storage 模型 |
| 初次使用 | 需要安装 Node 依赖并启动服务 | 无需 Node 构建，但依赖外网与浏览器环境 |
| 错误展示 | 初始化错误主要写入控制台 | 轮询 `_handTrackingError` 并显示错误 / 演示模式 |
| 共通逻辑 | 四阵型、识别、防抖、相机和特效 | 基本相同，多个问题也一并存在 |

HTML 版头部 CSP 放宽了内联脚本与动态求值，主要服务于当前浏览器编译方案。这个配置并不能解决网络不可达、摄像头权限、WASM 加载失败或 GPU 不支持的问题。

## 5. React 版运行

本次核验环境为 Node `v22.23.1`、npm `10.9.8`。锁定的 Vite `7.3.0` 在其包元数据中要求 Node `^20.19.0 || >=22.12.0`；使用符合该范围的环境再安装。

```bash
cd '/Users/mac/ZXN/code/A-project/3D/TheSwordArray/React版'
npm ci
npm run dev
```

以终端实际输出的地址为准。若 5173 已被占用，默认启动行为可能选择其他端口。

生产构建及本地预览：

```bash
npm run build
npm run preview
```

`build` 实际依次执行 `tsc -b` 和 `vite build`。本次成功生成 `dist/`。由于原目录没有 `node_modules`，安装与验证均在临时副本进行，没有向原项目写入依赖、缓存或构建产物。

`npm run lint` 当前不能作为有效质量门禁：项目声明了 ESLint 9 和对应脚本，但没有 `eslint.config.js/mjs/cjs`，命令在配置查找阶段失败，尚未检查业务源码。

## 6. HTML 版运行

原说明写“双击运行即可”。源码同时明确注释了 `file://` 下可能发生 WASM 加载失败；因此不能把双击文件视为所有浏览器都能正常手势控制的保证。

可在本机通过静态 HTTP 服务验证页面，避免直接文件路径带来的部分加载限制：

```bash
cd '/Users/mac/ZXN/code/A-project/3D/TheSwordArray/HTML版'
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/`。这仍需要 CDN、模型源可达及浏览器允许摄像头。HTML 版的外网加载和实际识别未包含在本次完整验收范围内。

## 7. 资源交付边界

React 版本地模型与 WASM 总计约 16.71 MB（15.94 MiB），它们在构建中作为静态文件复制，不体现在主 JavaScript 的体积数字里。

| 资源 | 字节数 | 作用 |
| --- | ---: | --- |
| `hand_landmarker.task` | 7,819,105 | 内含手检测与手关键点两个 TFLite 文件 |
| `vision_wasm_internal.js` | 205,745 | WASM 加载与运行时胶水代码 |
| `vision_wasm_internal.wasm` | 8,689,767 | 推理计算运行时 |

本地资源路径从站点根目录开始：`/models/wasm`、`/models/hand_landmarker.task`。如果未来把项目部署到 `/sword/` 一类子路径，必须同时核对 Vite `base` 与业务中的模型地址；只改 `base` 不会自动重写这些字符串。

当前未见后端上传摄像头图像的业务代码；推理调用发生在浏览器。这个结论仅针对自有源码，不代替对第三方运行时与实际网络请求的完整审计。
